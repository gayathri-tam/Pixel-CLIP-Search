# Pixel-CLIP Image Search

An image processing and retrieval system that converts an input image into a pixel-style image and uses the CLIP model to retrieve relevant images based on a text query.

## Project Workflow

Input Image
↓
Pixel Image Generation
↓
CLIP Model
↓
Text Query
↓
Matching Pixel Images

## Features

- Upload a random image
- Generate a pixel-style version
- Enter a text query
- Search pixel images using CLIP
- Display the original input image
- Display the processed pixel image
- Display other matching images

## Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- OpenAI CLIP
- Pillow
- NumPy
- Matplotlib
